# Snake

"Snake" is a simple arcade game where you control a snake on a board.
Your goal is to fill the entire board with the snake's body. 
The snake grows longer as it consumes food that appears in random locations. 
If the snake hits a wall or collides with itself, you lose.

## How It Works
After launching the program, a window will appear where you can select the board size from 4x4 to 10x10. 
If needed, you can adjust the game pace within the range of 100–1000 ms. 
Furthermore, there is an option to set the grid thickness on the board from 0 to 4, so the grid can be omitted entirely. 
Additionally, from the dropdown menu, you can choose one of the window sizes supported by your operating system. 
The size of the window itself can also be freely resized.
